# Check-In Switch

A [Chickadee Bandit](https://chickadeebandit.com/app-library/dead-mans-switch) app.

A dead-man's switch for peace of mind: check in on your schedule, and if you go silent past your chosen interval, the people you designate get an alert with your message and a link to any files you left for them.

## Features

- Check in on the schedule you choose.
- Designate who is alerted and write the message they receive.
- The alert fires only after the interval you set passes with no check-in.
- Contacts can come from the household Contacts app.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-dead-mans-switch/releases/latest/download/bundle.json
```
